# 喝水小记

一款明亮、轻量的每日饮水记录工具，采用可切换的莫兰迪配色。

## 功能

- 圆形进度环，直观看见今日饮水完成度
- 3 个可自定义的快捷容量
- 输入任意精确毫升数
- 可自定义每日饮水目标
- 今日进度与剩余目标提示，达标后继续累计
- 饮水记录补记、修改、删除、恢复与撤销
- 月历总览，可按日期查看饮水记录与达标情况
- 最近 7 天饮水趋势
- 奶油杏、雾霾蓝、鼠尾草、豆沙莓四套主题
- 自定义主色，自动生成协调的柔和配色
- 配色选择收纳在独立设置面板中
- 支持安装为 PWA，可添加到手机桌面并离线打开
- JSON 数据一键导出与导入，方便跨设备备份和恢复
- 数据保存在当前浏览器，并预留未来同步的数据层
- 手机与桌面自适应

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

推送到 `main` 分支后，GitHub Actions 会自动构建并发布 GitHub Pages。
