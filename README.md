# 喝水小记

一款明亮、轻量的每日饮水记录工具，采用可切换的莫兰迪配色。

## 功能

- 圆形进度环，直观看见今日饮水完成度
- 1–6 个可自定义的快捷杯量，默认 250 / 350 / 500 ml
- 首页一键进入杯量编辑，支持增减杯量、校验与恢复默认
- 输入任意精确毫升数
- 可自定义每日饮水目标
- 今日进度与剩余目标提示，达标后继续累计
- 饮水记录补记、修改、删除、恢复与撤销
- 月历总览，可按日期查看饮水记录与达标情况
- 最近 7 天饮水趋势
- 奶油杏、雾霾蓝、鼠尾草、豆沙莓四套主题
- 自定义主色，自动生成协调的柔和配色
- 配色选择收纳在独立设置面板中
- 支持安装为 PWA，可添加到手机桌面并离线打开
- JSON 数据一键导出与导入，方便跨设备备份和恢复
- 数据保存在当前浏览器，并预留未来同步的数据层
- 手机与桌面自适应

## 自定义快捷杯量

1. 点击首页快捷按钮旁的「自定义杯量」，或进入设置里的「自定义快捷杯量」。
2. 修改常用容量，也可以添加或删除杯量。每项支持 1–5000 ml 的整数，最多 6 项。
3. 点击「保存杯量」，首页按钮立即更新。关闭面板而未保存的修改不会生效。

「恢复默认」会把编辑框恢复为 250 / 350 / 500 ml，点击保存后生效。快捷杯量与每日目标分开保存，不会改动饮水历史；杯量设置也会包含在 JSON 备份中。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

`npm test` 可运行快捷杯量的校验与旧数据兼容测试。

推送到 `main` 分支后，GitHub Actions 会自动构建并发布 GitHub Pages。
