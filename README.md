# 喝水小记

一款明亮、轻量的每日饮水记录工具，采用可切换的莫兰迪配色。

## 功能

- 250 ml、350 ml、500 ml 快速记录
- 输入任意精确毫升数
- 今日进度与剩余目标提示
- 今日记录删除、恢复与撤销
- 最近 7 天饮水趋势
- 奶油杏、雾霾蓝、鼠尾草、豆沙莓四套主题
- 配色选择收纳在独立设置面板中
- JSON 数据一键导出与导入，方便跨设备备份和恢复
- 数据保存在当前浏览器，并预留未来同步的数据层
- 手机与桌面自适应

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

推送到 `main` 分支后，GitHub Actions 会自动构建并发布 GitHub Pages。
