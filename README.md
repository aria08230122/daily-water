# 喝水小记

一款明亮、轻量的生活记录工具，保留饮水小记，并加入便便记录与计时。采用可切换的莫兰迪配色，数据保存在本机。

## 功能

- 底部导航切换「喝水 / 便便」，也可通过 `#bowel` 直接打开便便页
- 便便快捷记一次，或「开始 → 计时 → 结束并自动保存」
- 计时开始时间立即存到本机，切页、锁屏、刷新或关闭后重开会按真实经过时间继续计算
- 结束后再选填形状、顺畅程度、颜色、量、腹痛和备注；关闭面板不会丢掉已保存的这一次
- 便便日历、补记、编辑时间与细节、删除和撤销；区分「未记录」与明确标记「这天没有」
- 圆形进度环，直观看见今日饮水完成度
- 1–6 个可自定义的快捷杯量，默认 250 / 350 / 500 ml
- 首页一键进入杯量编辑，支持增减杯量、校验与恢复默认
- 输入任意精确毫升数
- 可自定义每日饮水目标
- 今日进度与剩余目标提示，达标后继续累计
- 饮水记录补记、修改、删除、恢复与撤销
- 月历总览，可按日期查看饮水记录与达标情况
- 最近 7 天饮水趋势
- 奶油杏、雾霾蓝、鼠尾草、豆沙莓四套主题
- 自定义主色，自动生成协调的柔和配色
- 配色选择收纳在独立设置面板中
- 支持安装为 PWA，可添加到手机桌面并离线打开
- JSON 数据一键导出与导入，方便跨设备备份和恢复
- 数据保存在当前浏览器，并预留未来同步的数据层
- 手机与桌面自适应

## 自定义快捷杯量

1. 点击首页快捷按钮旁的「自定义杯量」，或进入设置里的「自定义快捷杯量」。
2. 修改常用容量，也可以添加或删除杯量。每项支持 1–5000 ml 的整数，最多 6 项。
3. 点击「保存杯量」，首页按钮立即更新。关闭面板而未保存的修改不会生效。

「恢复默认」会把编辑框恢复为 250 / 350 / 500 ml，点击保存后生效。快捷杯量与每日目标分开保存，不会改动饮水历史；杯量设置也会包含在 JSON 备份中。

## 便便记录与计时

1. 点击底部「便便」，点「开始」开始计时。
2. 点「结束并保存」，时间和用时会先写入本机，再打开选填细节面板。可以直接选择「稍后填写」。
3. 已经结束、不需要用时的情况，可以点「快捷记一次」。这种记录不会虚构时长。
4. 日历中选日期可以补记，点已有记录可以修改。忘记结束计时时，可在「调整时间」中修正开始、结束时间。

计时按开始日期归档，跨午夜也保留完整用时。一次只能有一个计时；取消计时需要确认，不会新增记录。支持 Web Locks 的浏览器会串行处理跨标签页的便便写入，并通过存储事件更新其他页面。未填写的细节保持为空，不会自动猜测腹痛或形状，也不提供诊断。

## 备份兼容

- 保留原有 `daily-water/store-v1` 饮水存储；便便数据独立存于 `daily-water/bowel-v1`，避免旧版页面覆盖新模块的数据。
- 新版 JSON 备份（`exportVersion: 2`）包含饮水、已完成的便便记录、无便便日期标记及设置。
- 正在计时的会话只留在本机，不导出到其他设备；请结束后再备份。
- 仍支持旧版原始饮水数据和 `exportVersion: 1` 备份，导入时保留现有便便记录与计时。
- 导入前会确认替换范围。完整备份不会覆盖正在进行的计时，需要先结束或取消。
- 两份数据均通过校验后才写入；如果写入失败，会尝试回滚并明确报告结果。
- 数据仍是本地保存，不是云端同步。请使用平时记录的设备和浏览器导出；不要在未备份时清除网站数据。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

`npm test` 可运行快捷杯量、计时状态、跨午夜、选填细节、旧备份兼容与导入回滚测试。

推送到 `main` 分支后，GitHub Actions 会自动构建并发布 GitHub Pages。
